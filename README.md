# Student Management System

A simple **Java-based Student Management System** that allows users to manage student records through a console-based interface.

## 📌 Project Overview

The Student Management System is a beginner-friendly Java project designed to practice **Java programming, OOP concepts, ArrayList, methods, loops, and conditional statements**.

The application provides a menu-driven interface for managing student information.

## ✨ Features

* Add a new student
* View all students
* Search for a student by ID
* Update student information
* Delete a student
* Calculate average marks
* Find the student with the highest marks
* Simple and easy-to-use console interface

## 🛠️ Technologies Used

* **Java**
* **ArrayList**
* **Scanner**
* Object-Oriented Programming (OOP)
* VS Code
* Git & GitHub
